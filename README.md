## 🤖 Introduction

This 3D Portfolio is a modern, interactive personal website that features:

- Animated 3D elements  
- Smooth scroll animations powered by GSAP  
- Responsive layout using Tailwind CSS  
- Multi-section showcase (About, Projects, Contact)  
- Mobile-friendly 3D experience  

It’s designed to highlight my skills, projects, and creativity in a visually engaging way.

---

## ⚙️ Tech Stack

- React  
- Three.js & React Three Fiber  
- GSAP  
- Tailwind CSS  
- Vite  

---

## 🔋 Features

- 3D model showcase for projects  
- Scroll-based animations  
- Smooth camera transitions  
- Responsive design for all devices  
- Micro-interactions for buttons and UI elements  
- Multi-section layout (About, Projects, Contact)
